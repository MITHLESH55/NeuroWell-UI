#  NeuroWell - AI Mental Wellness Assistant

##  Overview

NeuroWell is an AI-powered mental wellness assistant designed to help users track mental health, analyze trends, and receive personalized recommendations.

This system integrates:

*  Trend analysis
*  Goal tracking
*  AI-based recommendations

---

## Features

| Feature           | Description              |
| ----------------- | ------------------------ |
| Mood Tracking     | Analyze emotional trends |
| Goal System       | Set wellness goals       |
| AI Recommendation | Personalized suggestions |
| Trend Analytics   | Visual reports           |
| Authentication    | Secure login system      |


##  Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **AI Logic:** Rule-based / JS-based recommendation engine
* **Deployment:** GitHub Pages

##  Installation & Setup

```bash
git clone https://github.com/YOUR_USERNAME/NeuroWell-UI.git
cd NeuroWell-UI
```

Run locally:

```bash
npx live-server
```

🏗 System Architecture


User
 ↓
Frontend (HTML/CSS/JS)
 ↓
AI Recommendation Engine
 ↓
Analytics & Trend Module
 ↓
Dashboard Visualization


## 📊 Workflow

1. User logs in
2. Takes assessment
3. System analyzes responses
4. AI generates recommendations
5. Dashboard shows trends & goals
